# Python CLI Calculator

A simple and robust Python CLI calculator that performs basic arithmetic operations with input validation, type hints, and automated unit tests.

## Features
- Handles command line arguments via `sys.argv`.
- Validates user input and gracefully handles exceptions (`ValueError`, `ZeroDivisionError`).
- Fully typed with Python Type Hints.
- Covered by unit tests using `pytest`.
